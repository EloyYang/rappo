# 📞 통화기록 대시보드

> Rappo(라포) 앱이 녹취·카카오톡을 자동으로 정리한 결과입니다. 표 머리글을 누르면 정렬, 행을 누르면 노트가 열립니다.
> 전체 보기: [[통화기록.base|통화기록 데이터베이스 열기]]

## ✅ 할 일 · 🎂 챙길 날
왼쪽은 통화·카톡·회의에서 **내가 하기로 정한 일**이에요. 우선순위를 눌러 바꾸고 ✏️ 고치기 · 🗑 지우기 · 📅 캘린더에 넣기 · 📝 PARA 할 일 노트 만들기를 할 수 있어요. ＋ 로 직접 추가도 돼요.
🎙 **회의 녹음**: 왼쪽 리본의 마이크 아이콘(또는 명령 'Rappo 회의 녹음 시작')을 누르면 녹음하고, 끝내면 Rappo 가 회의록으로 정리해 내 할 일을 여기에 넣어요.
오른쪽은 대화에서 정한 일정(📅 캘린더에 넣기), 생일·기념일, 그리고 대화에서 이야기했거나 해마다 챙겨 온 날(어버이날, 설·추석 …)이에요. 7·3·1일 전과 당일에 맥 알림으로 알려 줘요.

```할일챙길날
```

## 🕘 최근 연락
카톡·통화 구분 없이 최근에 연락한 순서예요. 색이 칠해진 표시가 가장 마지막 연락 수단이에요.
**🔔 연락 챙기기**를 누르면 자주 연락하던 사람 중 평소보다 오래 연락이 끊긴 사람을 보여 줘요.

```최근연락
```

## 🔍 대화·통화 검색
- 방·연락처 칸에 이름(초성도 됨)을 입력해 고르면 그 사람과의 통화·카톡 횟수, 처음·마지막 연락이 위에 요약되고 대화 전체가 최신 날짜부터 보여요. 단어는 필요할 때만 넣으세요.
- 단어를 넣으면 카톡과 통화(요약·전사문)를 월에 상관없이 한 번에 찾고, 결과는 📞 통화 / 💬 카카오톡 구역으로 나눠 보여요. 오른쪽 위 **전체 / 💬 카톡 / 📞 통화** 로 좁힐 수 있어요.
- **📅 날짜로 보기**: 그날의 카톡 방과 통화를 시간 순으로 펼쳐요. ◀ ▶ 로 대화가 있는 날로 이동해요. 줄을 누르면 원래 노트의 그 줄이 열려요.

```대화검색
```
