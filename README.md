# Rappo(라포) — 통화 녹취·카카오톡을 옵시디언에 자동 정리

소개 페이지: https://eloylab.it/rappo/

통화 녹음 파일을 맥 안에서 음성인식·화자 구분하고, 카카오톡 맥 앱의 대화를 읽어서
옵시디언 볼트에 **사람별로** 통화·대화 기록을 모아 줍니다.
- **🏠 라포 홈 (한 화면)**: 남은 할 일·오늘 일정·이번 달 지출·오늘 연락, 할 일, 챙길 날·일정, 이번 달 소비, 연락처 카드, 🔍 대화·통화 통합 검색(버튼)
- **💳 소비**: 현대카드 카톡 알림·승인 문자·이용내역 파일 → 월·년 보기, 분류(건별·가게별), 예산
- **할 일**: 통화·카톡·회의에서 *내가 하기로 정한 일*만 엄격하게 골라 마감·상대·맥락과 함께 모음 (근거 문장 확인 + 재확인).
  우선순위·고치기·지우기, 📅 캘린더에 넣기, 📝 PARA 할 일 노트 만들기
- **챙길 날**: 생일·기념일(음력 포함), 카톡에서 생일 축하한 기록으로 생일 추정, 대화에서 이야기했거나 해마다 챙겨 온 어버이날·설·추석 …
  7·3·1일 전과 당일에 맥 알림
- **대화에서 정한 일정 → 캘린더**: 맥 캘린더(구글 캘린더 연결 포함)에 바로 넣기
- **회의록**: 옵시디언에서 🎙 새 회의로 녹음 → 받아 적기·화자 구분 → 요약·결정 사항·액션 아이템 → 내 할 일은 할 일 목록에
- **로컬 AI**: 요약·할 일·회의록을 Apple MLX 로컬 모델(기본 Qwen3.5 4B)로 — 내용이 맥 밖으로 나가지 않음. Claude Code 도 선택 가능
- **정리 시간**: 실시간 / 받아 적기는 바로·AI 정리는 정해진 시간에 / 모두 정해진 시간(예: 새벽 2~6시)에 몰아서

## 설치 (한 번만)

준비물: Apple Silicon 맥, [Homebrew](https://brew.sh), [옵시디언](https://obsidian.md)(볼트 하나 이상), 카카오톡 맥 앱(로그인)

1. **[Rappo.zip 내려받기](https://github.com/EloyYang/rappo/releases/latest/download/Rappo.zip)** → 압축을 풀어
   `Rappo` 폴더를 `~/Documents` 같은 곳에 둡니다. 설치 뒤에도 앱이 이 폴더의 코드를 쓰니 지우지 마세요.
2. 터미널에서:
   ```bash
   bash ~/Documents/Rappo/install.sh
   ```
   (또는 `git clone https://github.com/EloyYang/rappo.git ~/Documents/Rappo` 후 같은 명령)
   - 녹취 폴더를 묻습니다 (휴대폰 통화 녹음이 동기화되는 폴더).
   - 이미 녹취가 있으면 모두 변환할지 묻습니다 (기본: 지금부터 생기는 것만).
   - 옵시디언 볼트를 찾아 **대시보드·표·검색 플러그인을 자동으로 넣습니다** (볼트가 여러 개면 번호로 고름).
   - 메뉴막대 앱 `~/Applications/Rappo.app` 을 만들고 실행합니다.
3. 끝에 안내되는 대로:
   - 시스템 설정 → 개인정보 보호 및 보안 → **전체 디스크 접근 권한** 에 `Rappo.app` 추가
   - 메뉴막대 Rappo → **로그인 시 자동 실행**
   - 메뉴막대 Rappo → **내 목소리 등록…** (전사문에서 '나'를 구분)
   - 옵시디언을 열고 플러그인 사용을 허용 → `통화기록/라포 홈` 열기

다시 설치해도(업데이트) 안전합니다. 기존 설정과 노트는 그대로 두고 플러그인만 최신으로 바꿉니다.

## PARA 노트 정리 (선택)

설치할 때 "PARA 노트 정리 방식도 함께 설치할까요?"에 y 를 고르면 함께 넣어요 (`python3 obsidian_setup.py --vault ~/볼트 --para`).
- 폴더 `0. Inbox · 1. Projects · 2. Areas · 3. Resources · 4. Archive`, 템플릿(`_Templates`의 노트·프로젝트·영역·자원)
- **PARA 대시보드**: 할 일 보드(시작 전·진행 중·완료, 칸마다 ＋), 진행 중 프로젝트, 마감 일정, 체크리스트, 🎙 새 회의
- **자동 이동**: 노트의 `type`·`status`·`project`·`area` 속성에 맞춰 알맞은 폴더로 옮겨요
- 라포 홈에도 시작 전·진행 중 노트와 프로젝트가 함께 보여요
이미 PARA 폴더를 쓰는 볼트는 있는 폴더·템플릿·노트를 건드리지 않고 플러그인만 최신으로 바꿔요.

## 녹취 파일 이름

`[이름_]전화번호_YYYYMMDDHHMMSS.m4a` (예: `홍길동_01012345678_20261126143000.m4a`)
- 같은 번호는 **가장 최근 녹취에 붙은 이름**으로 모든 노트가 맞춰집니다. 이름이 없으면 `정보 없음`.

## 메뉴막대 앱

메뉴막대의 겹친 말풍선 아이콘을 누르면:
- **지금 정리하기** · **옵시디언에서 라포 홈 열기** · **설정…** · 종료

메뉴 맨 위에는 상태와 2주 안의 챙길 날이 보여요. 전체 디스크 접근 권한이 풀리면 ⚠️ 로 알려 줘요.

설정 창 (바꾸면 바로 적용돼요)
- **일반**: 녹취 폴더, 이전 녹취 건너뛰기, 옵시디언 볼트와 대시보드 설치, 로그인 시 자동 실행, 전체 디스크 접근 권한 상태
- **카카오톡**: 가져오기 켜기/끄기, 가져오는 때(새 대화가 오면 바로 / 간격마다), 내 카톡 이름
- **정리·AI·캘린더**: 정리 시간(실시간·정해진 시간), 통화 요약과 사용할 AI(자동·로컬·Claude)·로컬 모델, 넣을 캘린더와 접근 허용
- **고급**: 빈 요약 채우기, 로그, 내 목소리 등록, 녹취 폴더 확인 방식, 카톡 내보내기 폴더, 처음 값으로

## 수동 실행

```bash
bash run.sh --kakao-db          # 녹취 + 카카오톡
bash run.sh --resummarize       # 비어 있는 요약만 채움
bash run.sh --catch-up          # 미뤄 둔 AI 정리(빈 요약·통화/카톡 할 일·회의록)를 한꺼번에
bash run.sh --meetings          # 옵시디언에서 녹음한 회의만 정리
bash run.sh --redo-tasks        # 최근 7일 통화에서 할 일 다시 찾기
bash run.sh --sync-names        # 연락처·통화 노트 이름만 다시 정리
bash run.sh --setup-obsidian    # 볼트에 대시보드·플러그인 설치
python3 obsidian_setup.py --vault ~/볼트 --base "통화기록"   # 볼트·폴더 직접 지정
```

## AI 켜기 (요약·할 일·회의록)

기본은 **로컬 모델**이에요. Apple 실리콘용 [MLX](https://github.com/ml-explore/mlx)로 Qwen3.5 4B(4bit, 약 3GB)를 돌려요.
설치할 때 "로컬 AI 설치"에 y 를 고르면 돼요. 필요할 때만 띄우고 끝나면 내려서 평소엔 메모리를 쓰지 않아요.
(8GB M1 맥에서 같은 모델을 Ollama 로 돌릴 때보다 통화 요약이 약 2배 빨랐어요. Ollama 가 있으면 대신 쓸 수도 있어요.)
[Claude Code](https://claude.com/claude-code)의 `claude` 명령을 쓰고 싶으면 설정 › 정리·AI·캘린더 › 사용할 AI 에서 고르세요.
AI 가 없으면 요약·할 일만 빠지고 나머지는 정상 처리됩니다.

## 캘린더

설정 › 정리·AI·캘린더 › **접근 허용**을 누르고 넣을 캘린더를 고르세요. 구글 캘린더는 시스템 설정 › 인터넷 계정에
Google 계정을 추가하면 목록에 나타나요. 대시보드에서 📅 를 누른 일정·할 일과 60일 안의 챙길 날이 들어가요.

## 회의록

PARA 대시보드나 프로젝트·영역 노트(`type: project/area`)의 **🎙 새 회의**를 누르면 옵시디언에서 녹음해요.
끝내면 회의 노트가 그 프로젝트 폴더에 생기고, Rappo 가 받아 적어 회의록과 내 할 일을 채워요.
(옵시디언에 마이크 권한이 필요해요. 회의 창의 🎤 마이크 확인으로 요청할 수 있어요.)

## 로그·제거

- 로그: 메뉴막대 Rappo → 로그 보기 (`~/.venvs/rappo/logs/rappo.log`)
- 제거: `bash uninstall.sh` (노트는 남음)

## 구성 파일

| 파일 | 역할 |
|---|---|
| `rappo.py` | 녹취 음성인식·화자 구분, 통화·연락처 노트, 이름 정리, 요약, 카톡 연동 호출 |
| `llm.py` | AI 호출 한곳 (로컬 MLX·Ollama / Claude Code) |
| `tasks.py` | 통화·카톡·회의에서 내가 하기로 정한 일 찾기 → `할 일.md` |
| `meetings.py` | 옵시디언에서 녹음한 회의 → 회의록·내 할 일 |
| `spend.py` | 현대카드 승인 문자·이용내역 파일 → 💳 소비 |
| `kakao.py` / `kakao_db.py` | 카톡 대화 → 방·연락처 노트 / 카카오톡 맥 DB 읽기 |
| `obsidian_setup.py`, `obsidian/` | 옵시디언 볼트 세팅 (라포 홈·표 템플릿, `rappo` 플러그인, `para/` PARA 템플릿·플러그인) |
| `app/` | 메뉴막대 앱 소스(`Rappo.swift`)와 빌드 스크립트 |
| `run.sh`, `install.sh`, `uninstall.sh`, `make_dist.sh` | 실행 / 설치 / 제거 / 배포용 압축 |
| `config.sh` | 설치할 때 생기는 내 맥 전용 설정 (배포본에는 넣지 않음) |

> 카카오톡 앱이 큰 업데이트를 하면 데이터 형식이 바뀌어 `kakao_db.py` 가 동작하지 않을 수 있습니다.

## 개인정보

녹음 파일과 카카오톡 대화는 내 맥에서만 읽고, 결과는 내 옵시디언 볼트에만 저장합니다. Rappo는 어떤 서버로도
데이터를 보내지 않습니다. 로컬 모델을 쓰면 요약·할 일·회의록도 모두 맥 안에서 만들어요.
(AI 로 Claude Code 를 고르면 전사문·대화가 Claude Code 를 통해 Anthropic 으로 전송됩니다.)
통화 녹음과 대화 기록은 상대방의 개인정보이기도 하니, 관련 법과 상대방의 뜻을 존중해 사용하세요.
