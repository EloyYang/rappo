# Rappo(라포) — 통화 녹취·카카오톡을 옵시디언에 자동 정리

소개 페이지: https://eloylab.it/rappo/

통화 녹음 파일을 맥 안에서 음성인식·화자 구분하고, 카카오톡 맥 앱의 대화를 읽어서
옵시디언 볼트에 **사람별로** 통화·대화 기록을 모아 줍니다.
- 대시보드: 최근 연락(카톡·통화 구분 없이), 대화·통화 통합 검색, 날짜별 보기, 연락처·카톡방 표
- 모든 처리는 내 맥 안에서 이뤄집니다(요약만 선택적으로 `claude` CLI 사용).

## 설치 (한 번만)

준비물: Apple Silicon 맥, [Homebrew](https://brew.sh), [옵시디언](https://obsidian.md)(볼트 하나 이상), 카카오톡 맥 앱(로그인)

1. **[Rappo.zip 내려받기](https://github.com/EloyYang/rappo/releases/latest/download/Rappo.zip)** → 압축을 풀어
   `Rappo` 폴더를 `~/Documents` 같은 곳에 둡니다. 설치 뒤에도 앱이 이 폴더의 코드를 쓰니 지우지 마세요.
2. 터미널에서:
   ```bash
   bash ~/Documents/Rappo/install.sh
   ```
   (또는 `git clone https://github.com/EloyYang/rappo.git ~/Documents/Rappo` 후 같은 명령)
   - 녹취 폴더를 묻습니다 (휴대폰 통화 녹음이 동기화되는 폴더).
   - 이미 녹취가 있으면 모두 변환할지 묻습니다 (기본: 지금부터 생기는 것만).
   - 옵시디언 볼트를 찾아 **대시보드·표·검색 플러그인을 자동으로 넣습니다** (볼트가 여러 개면 번호로 고름).
   - 메뉴막대 앱 `~/Applications/Rappo.app` 을 만들고 실행합니다.
3. 끝에 안내되는 대로:
   - 시스템 설정 → 개인정보 보호 및 보안 → **전체 디스크 접근 권한** 에 `Rappo.app` 추가
   - 메뉴막대 Rappo → **로그인 시 자동 실행**
   - 메뉴막대 Rappo → **내 목소리 등록…** (전사문에서 '나'를 구분)
   - 옵시디언을 열고 플러그인 사용을 허용 → `통화기록/통화기록 대시보드` 열기

다시 설치해도(업데이트) 안전합니다. 기존 설정과 노트는 그대로 두고 플러그인만 최신으로 바꿉니다.

## 녹취 파일 이름

`[이름_]전화번호_YYYYMMDDHHMMSS.m4a` (예: `홍길동_01012345678_20261126143000.m4a`)
- 같은 번호는 **가장 최근 녹취에 붙은 이름**으로 모든 노트가 맞춰집니다. 이름이 없으면 `정보 없음`.

## 메뉴막대 앱

- 녹취 폴더에 새 파일이 생기면 자동 처리 (네트워크 드라이브는 주기적으로 확인)
- 카카오톡 데이터가 바뀌면 자동 반영 (또는 일정 주기)
- 설정…: 녹취·볼트 폴더, 반영 방식, 요약 여부, "이 시각 이후 녹취만" 등
- 옵시디언에 대시보드·검색 설치: 볼트를 바꿨거나 옵시디언을 나중에 설치했을 때

## 수동 실행

```bash
bash run.sh --kakao-db          # 녹취 + 카카오톡
bash run.sh --resummarize       # 비어 있는 요약만 채움 (claude 로그인 필요)
bash run.sh --sync-names        # 연락처·통화 노트 이름만 다시 정리
bash run.sh --setup-obsidian    # 볼트에 대시보드·플러그인 설치
python3 obsidian_setup.py --vault ~/볼트 --base "통화기록"   # 볼트·폴더 직접 지정
```

## 요약 켜기 (선택)

요약은 [Claude Code](https://claude.com/claude-code)의 `claude` 명령으로 만듭니다. 터미널에서 한 번 로그인해 두면
자동 실행에서도 요약이 채워집니다. 없으면 요약만 빠지고 나머지는 정상 처리됩니다.

## 로그·제거

- 로그: 메뉴막대 Rappo → 로그 보기 (`~/.venvs/rappo/logs/rappo.log`)
- 제거: `bash uninstall.sh` (노트는 남음)

## 구성 파일

| 파일 | 역할 |
|---|---|
| `rappo.py` | 녹취 음성인식·화자 구분, 통화·연락처 노트, 이름 정리, 카톡 연동 호출 |
| `kakao.py` / `kakao_db.py` | 카톡 대화 → 방·연락처 노트 / 카카오톡 맥 DB 읽기 |
| `obsidian_setup.py`, `obsidian/` | 옵시디언 볼트 세팅 (대시보드·표 템플릿, `rappo` 플러그인) |
| `app/` | 메뉴막대 앱 소스(`Rappo.swift`)와 빌드 스크립트 |
| `run.sh`, `install.sh`, `uninstall.sh`, `make_dist.sh` | 실행 / 설치 / 제거 / 배포용 압축 |
| `config.sh` | 설치할 때 생기는 내 맥 전용 설정 (배포본에는 넣지 않음) |

> 카카오톡 앱이 큰 업데이트를 하면 데이터 형식이 바뀌어 `kakao_db.py` 가 동작하지 않을 수 있습니다.

## 개인정보

녹음 파일과 카카오톡 대화는 내 맥에서만 읽고, 결과는 내 옵시디언 볼트에만 저장합니다. Rappo는 어떤 서버로도
데이터를 보내지 않습니다. (요약을 켜면 통화 전사문이 Claude Code 를 통해 Anthropic 으로 전송됩니다.)
통화 녹음과 대화 기록은 상대방의 개인정보이기도 하니, 관련 법과 상대방의 뜻을 존중해 사용하세요.
